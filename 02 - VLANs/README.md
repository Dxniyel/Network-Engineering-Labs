# VLAN Configuration

### 1. Simple VLAN Configuration
**File:** `Simple VLAN Configuration.pkt`

This lab demonstrates how to create and configure VLANs on a Cisco switch.

- Create VLANs and assign switch ports to specific VLANs.
- Configure access ports for end devices.
- Understand how VLANs separate devices into different broadcast domains.
- Verify VLAN configurations using `show vlan brief`.

### 2. VLAN and Native VLAN Configuration
**File:** `VLAN and Native VLAN Configuration.pkt`

This lab demonstrates VLAN trunking and native VLAN configuration between Cisco switches.

- Configure VLANs across multiple switches.
- Configure trunk ports using IEEE 802.1Q.
- Understand how trunk links carry traffic from multiple VLANs.
- Configure a native VLAN for untagged traffic.
- Verify trunk configurations using `show interfaces trunk`.
